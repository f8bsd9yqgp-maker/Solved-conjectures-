# Graffiti.pc Conjecture 412e — Critical independent sets and maximum degree in a pendant neighborhood

Let G be a finite simple connected graph on n>2 vertices, P its pendants, S=N(P), H the union of all maximum critical independent sets, and c the order of a largest component of G[S] (zero if empty). An independent set I is critical if it maximizes |I|−|N(I)|; maximum critical means largest cardinality among critical sets.

First P⊆H for every such graph. Fix a pendant p with support s and any maximum critical independent set I. If p∉I and s∉I, adding p preserves independence and increases cardinality without decreasing the difference, impossible. If s∈I, replace s by p. The old neighborhood contains p, the new neighborhood omits p and adds at most s, so the difference does not decrease. Cardinality is unchanged, and the replacement is again maximum critical, containing p. Each support has a distinct private pendant, so |H|≥|P|≥|S|≥c. This proves the first (general-graph) clause of both #412a and #412b.

For bipartite G, H is the union of all maximum independent sets (the corona). Indeed, let μ be a maximum matching size. Any independent I has at least |I|−(n−2μ) distinct matching partners in N(I), hence |I|−|N(I)|≤n−2μ. For a maximum independent set, maximality gives N(I)=V∖I and König's theorem gives α=n−μ, so equality holds. All maximum independent sets are therefore critical and no critical set can have greater cardinality. Also there exists a maximum independent set K containing all pendants and no supports: any selected support with two or more leaves could be replaced by all its leaves, increasing size; any selected support with one leaf can be replaced by that leaf without decreasing size. Replacing all selected supports and adding any remaining omitted pendant gives the claim.

Assume G is bipartite. Put X=N(S), and Δ_X=Δ(G[X]), the maximum degree measured in the induced subgraph (zero for the empty graph if that convention is used). The conjecture is |H|≥1+Δ_X.

If X is empty, the bound under the zero convention holds since α≥1; otherwise the maximum over the empty graph is undefined. If Δ_X≤1, the bound follows because a bipartite graph of order >2 has α≥2. Now choose v∈X with |N(v)∩X|=Δ_X≥2 and put I=N(v)∩X. This is independent because G is bipartite, and v is not a pendant. Since v∈X, it has a support neighbor s∈S; choose a pendant p adjacent to s. Then p≠v and p∉I, since p has no neighbor except s≠v. If α≥|I|+1 we are done. Otherwise I is maximum and I⊆H; P⊆H implies p∈H, so |H|≥|I|+1. ∎
