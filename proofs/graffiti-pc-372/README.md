# Graffiti.pc Conjecture 372 — Vertex cover and path partition of a tree

24 November 2026 (US Central). AI-assisted candidate proof, not independently refereed or Lean-verified. Statement from [the August 2026 WOW II transcription](https://github.com/Kuberwastaken/c5-k4/blob/main/corpora/graffiti_pc_wow2.json), listed open there. The November primary PDF returned an error on direct retrieval and the available extracted text ends at #341; later-page status is not established. The current Davis completed index does not list this result. Targeted searches did not identify an exact earlier complete resolution, but discovery priority is not established.

Let T be a finite tree on n>2 vertices, p the minimum number of vertex-disjoint paths covering V(T), τ the minimum vertex cover size, and t the total domination number. The stated quotient inequality is t≥τ/(p−1), defined only for p≥2. We prove it throughout that domain.

Let D be a minimum total dominating set of size t, c the number of components of T[D], and U=V∖D. Each D-component has at least two vertices, so c≤floor(t/2). Contract these components. Every U vertex has a D-neighbor, and the contracted graph is a tree. Counting edges gives |E(T[U])|≤c−1. Every edge in a matching either touches D (at most t such matching edges) or belongs to T[U] (at most c−1). By König's theorem τ=μ, the maximum matching size of the bipartite tree. Hence τ≤t+c−1≤2t. If p≥3 this gives τ≤(p−1)t.

Suppose p=2. A path cover of two paths is obtained by deleting exactly one edge of the tree, so Δ≤3 and at most two vertices have degree three; if there are two they are adjacent, namely the endpoints of the removed edge. Total domination gives n≤Σ_{v∈D}deg(v)≤2t+2. If τ>t, then τ≤floor(n/2) forces n=2t+2, τ=n/2, and both degree-three vertices belong to D. All inequalities are equalities: no leaf is selected, and every vertex has exactly one selected neighbor. The two adjacent degree-three vertices are each other's unique selected neighbors.

The tree consists of their joining edge and four pendant paths, two at each degree-three vertex. Along each arm starting at its selected degree-three vertex, the efficient total domination condition forces the selected/unselected pattern D,U,U,D,D,U,U,D,D,... (the first arm vertex is unselected because the hub already has a selected neighbor; each next status follows from the preceding internal vertex having exactly one selected neighbor). At the terminal leaf, which is unselected, its preceding vertex must be selected. Thus each of the four arms has length 1 modulo 4, in particular odd. A perfect matching must match the hub to the first vertex of each odd arm (otherwise that arm's odd number of vertices must be perfectly matched internally). A hub has two odd arms, impossible. This contradicts τ=n/2 and proves τ≤t for p=2. ∎

The path case p=1 is excluded from the literal quotient because of division by zero. The corresponding multiplied inequality would be false for nontrivial paths; no claim to have repaired this original domain defect is made.

Exact finite check: all 975 nonisomorphic trees of orders 3–12 with p≥2 passed, including 84 with p=2. Path cover was computed by enumerating subsets of tree edges to delete until maximum remaining degree is at most two, and matching/total domination were computed exactly.
