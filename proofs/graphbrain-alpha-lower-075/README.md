## Statement
alpha ≥ |Per|−Delta²−|C|.

## Disproof
Take a complete rooted binary tree of depth h≥4, with every leaf augmented to a K5 by adding four private vertices. The root is the unique center, Delta=5, and the peripheral set consists of all four new vertices per leaf, of size 4*2^h. This follows because diameter 2h+2 is realized by new vertices in opposite root branches; every original tree vertex has smaller eccentricity. The clique partition of leaf cliques and singleton internal tree vertices gives alpha≤2^h+(2^h−1)=2^(h+1)−1. RHS=4*2^h−26>2^(h+1)−1 for h≥4. At h=4, alpha≤31<38.
