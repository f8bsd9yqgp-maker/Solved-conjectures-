## Statement
alpha ≤ (|irreducible part|−exp(WP))².

## Disproof
Take B(50,3), 50 triangles joined by bridges between consecutive hubs. Its alpha=50 by the clique partition. For every nonempty independent set I, each member has two distinct neighbors within its own triangle, and different selected vertices are in different triangles, so |N(I)|≥2|I|. The unique maximum critical independent set is empty; the author defines the independence irreducible part as the complement of its closed neighborhood, hence all 150 vertices. WP=5, since 48 interior hubs have degree four, and maximum degree is four. From the exponential series 2.7<e<2.72, so 143<e^5<150. The conjectured RHS is <49<50. This is a standalone exact witness.
